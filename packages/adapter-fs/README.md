# @stowage/adapter-fs

A storage rooted in one directory of the local file system.

The package is not released yet and exports no API. What it will hold is written in
[`docs/spec.md`](https://github.com/stowage-js/stowage/blob/main/docs/spec.md#6-stowageadapter-fs), which is the contract: a caller may rely on what that document
states and on nothing else a package happens to export.

## Runtimes

Node 24 and later, Bun and Deno. The Bun and Deno versions CI last ran green are named here once CI has run them.
