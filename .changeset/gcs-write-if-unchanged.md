`adapter-gcs` declares `writeIfUnchanged` and `deleteIfUnchanged`. `put`, `copy` and `move` with `onlyIf: { etag }` send the generation as `ifGenerationMatch` wherever `"absent"` sends `0`: on the `uploadType=multipart` insert, the start of a resumable session, every call of `rewriteTo` and `objects.move`. A key that holds another generation, or none, rejects with `PreconditionFailed`, `key` set to `to` for `copy` and `move`. `delete(key, { onlyIf: { etag } })` sends one `DELETE` carrying `ifGenerationMatch` rather than a batch, and reads its answer as that key's entry: `412 conditionNotMet` is a `PreconditionFailed` entry, and so is a `404 notFound` that is no missing bucket, which is no success under a precondition. A refusal after an attempt without a response or with a `5xx` is the entry of that earlier failure, `retryable: true`, since whether this call deleted the object is open. An `etag` that is no generation, decimal digits without a leading zero, other than `0` and at most 2⁶³−1, never matches: `put`, `copy`, `move` and `presignPut` reject it with `PreconditionFailed` and `attempts: 0` without a request or a URL, and a conditional `delete` reports it as the key's entry. `0` is no generation here, since `ifGenerationMatch=0` means that no object exists. `presignPut` signs `{ etag }` as `x-goog-if-generation-match` with the generation and returns it in `headers` (ADR 0071, ADR 0073, ADR 0074).
